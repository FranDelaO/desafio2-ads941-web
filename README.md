# desafio2-ads941-web

Repositorio de ejemplo del Desafío 2 de la asignatura Análisis y Diseño de Sistemas Informáticos (ADS941), Universidad Don Bosco.

## Contenido
- `index.html`: página principal.
- `css/styles.css`: hoja de estilos.
- `js/main.js`: interacción básica.

## Cómo visualizarlo
Abrir `index.html` en cualquier navegador o publicarlo con GitHub Pages.
